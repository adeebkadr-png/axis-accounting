# المحاسب الذكي

نظام محاسبة عربي متكامل على غرار «الأمين»، أبسط في الاستخدام ومدعوم بالذكاء الاصطناعي (Claude).

## التشغيل

**في المتصفح:** انقر مرتين على `run.bat` — يثبّت المتطلبات في أول مرة ثم يفتح البرنامج على `http://127.0.0.1:8000`.

**على أكثر من جهاز (شبكة المحل):** شغّل `run_network.bat` على جهاز واحد فقط، وافتح على بقية الأجهزة العنوان الذي يظهر (مثل `http://192.168.1.5:8000`). قاعدة البيانات تعمل بوضع WAL فيمكن لعدة مستخدمين العمل معاً.

**كتطبيق سطح مكتب (نافذة مستقلة):** `python desktop.py` — أو ابنِ ملفاً تنفيذياً بنقرة على `build_exe.bat`
فينتج `dist\SmartAccounting\SmartAccounting.exe` يعمل على أي جهاز ويندوز بدون تثبيت Python.

**أول تشغيل:** يطلب البرنامج إنشاء حساب المدير (اسم مستخدم وكلمة مرور)، وهذا الحساب يملك كل الصلاحيات
ويستطيع إضافة بقية المستخدمين. ثم من **الإعدادات** أضف مفتاح Anthropic API لتفعيل الذكاء الاصطناعي
(من console.anthropic.com).

**وكيل الطباعة (لطابعة USB على جهاز الكاشير):** شغّل `run_agent.bat` على جهاز الكاشير، اضبط الطابعة في `agent.json`، ثم اختر «وكيل الطباعة المحلي» من الإعدادات ← الطابعات والأجهزة.

**اتصال مشفّر:** `run_https.bat` ينشئ شهادة خاصة بشبكتك ويشغّل البرنامج على `https://…:8443`.

**تشغيل تلقائي مع ويندوز:** `install_autostart.bat` (والإلغاء بـ`uninstall_autostart.bat`).

**دليل المستخدم:** زر ❓ أعلى البرنامج، أو الملف `static/guide.html` — قابل للطباعة.

**الاختبارات:** `run_tests.bat` يشغّل ٨٤ اختباراً آلياً تتحقق من توازن القيود والمخزون والضريبة والصلاحيات والإقفال قبل أي تعديل جديد.

**للتجربة ببيانات جاهزة** (على قاعدة بيانات فارغة فقط):
```
cd backend
python seed_demo.py
```

## الميزات

| القسم | المحتوى |
|---|---|
| الفواتير | مبيع، شراء، مرتجع مبيع، مرتجع شراء. نقداً أو آجلاً، مع حسم وضريبة وطباعة، وإدخال سريع بلوحة المفاتيح والباركود |
| 🛒 نقطة البيع | شاشة كاشير سريعة: مسح باركود، شبكة مواد باللمس، تعديل الكميات، دفع نقدي أو آجل مع حساب الباقي، وطباعة إيصال حراري 80 ملم. F2 للدفع وF4 للزبون |
| الورديات | فتح وردية برصيد افتتاحي، متابعة مبيعاتها لحظياً، وإغلاقها بجرد الصندوق — والعجز أو الزيادة يُرحَّل تلقائياً إلى حساب «عجز وزيادة الصندوق» |
| الوحدات المتعددة | لكل مادة وحدات إضافية (كرتونة = 12 قطعة) بسعر وباركود لكل وحدة، والمخزون يُخصم دائماً بالوحدة الأساسية |
| الأسعار والعروض | قوائم أسعار (جملة/مفرق) تُسند للعملاء، وعروض بحسم نسبة أو سعر ثابت بفترة وأقل كمية — ويُختار دائماً السعر الأفضل للزبون |
| باركود الموازين | قراءة ملصقات الميزان (13 رقماً تحمل الوزن أو المبلغ) تلقائياً في نقطة البيع، مع ضبط البادئة من الإعدادات |
| 🖨️ الطباعة المباشرة | إيصال حراري يُطبع فوراً بلا حوار (ESC/POS) على طابعة شبكة أو USB، بنص عربي صحيح (يُرسم كصورة). ثلاثة أوضاع لكل جهاز: متصفح / من الخادم / وكيل محلي |
| الأجهزة | فتح درج النقود تلقائياً عند البيع النقدي أو يدوياً، طابعة مطبخ مستقلة، قراءة ميزان متصل (COM)، وشاشة عرض للزبون على نافذة ثانية |
| ملصقات الباركود | طباعة ملصقات 50×30 ملم بالاسم والباركود والسعر لأي عدد من المواد |
| 🍽️ المطعم | صالات وطاولات بحالة حية، طلبات صالة/سفري/توصيل، عدة فواتير للطاولة، نقل ودمج وفصل الطلبات، كشف حساب مبدئي، رسم خدمة وأجرة توصيل |
| الوصفات | لكل طبق مكوّناته: بيعه يخصم المكوّنات من المخزون، وتكلفته = مجموع تكلفتها، مع نسبة تكلفة الطعام لكل طبق |
| المطبخ | إرسال الأصناف الجديدة فقط للمطبخ، تذاكر مجمّعة حسب قسم التحضير، شاشة مطبخ (KDS) تتحدّث تلقائياً مع زر «جاهز» |
| الإضافات | خيارات بفرق سعر أو مجانية («إضافة جبنة +5»، «بدون بصل») وملاحظة حرة للمطبخ |
| مكوّنات المنتج | لأي منتج عدد **غير محدود** من المكوّنات مع نسبة هدر لكل مكوّن، وتحضيرات وسيطة (وصفة داخل وصفة) تُفكّ إلى موادها الخام تلقائياً. تُعرَّف من زر 🧾 في المواد أو عند إنشاء المنتج |
| الأصناف غير المخزنية | خدمات وأصناف تُباع بلا جرد (لا كمية ولا تكلفة) |
| المخزون | جرد مستمر بمتوسط التكلفة **لكل مستودع**، منع البيع بأكثر من المتوفر، تنبيه النقص، وحساب هامش الربح |
| الدفعات والصلاحية | تتبّع اختياري لكل مادة: رقم الدفعة وتاريخ الانتهاء عند الشراء، والبيع يخرج تلقائياً من الأقرب انتهاءً (FEFO)، مع تقرير المواد المنتهية والقريبة من الانتهاء |
| الجرد الفعلي | ورقة جرد قابلة للطباعة لكل مستودع، إدخال الكميات المعدودة، وترحيل فرق القيمة تلقائياً إلى حساب «فروقات الجرد وتلف المخزون» |
| أوامر الشراء | أوامر بحالات (مسودة/مرسل/مستلم/ملغى)، تحويلها إلى فاتورة شراء بضغطة، واقتراح إعادة الطلب حسب سرعة البيع وحد الطلب وآخر سعر ومورد |
| متغيرات المادة | لون/قياس كمواد مستقلة في المخزون مرتبطة بالمادة الأصل |
| المستودعات | عدد غير محدود من المستودعات، رصيد كل مادة في كل مستودع، وتحويل البضاعة بينها بسند تحويل قابل للإلغاء |
| الحسابات | دليل حسابات شجري، قيود يومية مزدوجة، وسندات قبض ودفع. لكل عميل ومورد حساب فرعي يُنشأ تلقائياً |
| الضريبة | ضريبة القيمة المضافة على الفواتير بنسبة قابلة للتعديل، وترحيل تلقائي لضريبة المخرجات (حـ/24) والمدخلات (حـ/115)، مع تقرير الإقرار الضريبي |
| العملات | عملة أساسية + أي عدد من العملات بأسعار صرف. الفواتير والسندات بأي عملة، والقيود كلها بالعملة الأساسية مع حفظ المبلغ الأصلي |
| الأرصدة الافتتاحية | شاشة لإدخال أرصدة الحسابات والعملاء والموردين عند بدء الاستخدام، وبضاعة أول المدة بالكميات والتكاليف |
| المستخدمون | حسابات بكلمات مرور، أدوار جاهزة (مدير، محاسب، كاشير، أمين مستودع) و17 صلاحية قابلة للتخصيص لكل مستخدم، مع تسجيل من نفّذ كل عملية |
| الرقابة | تعديل الفواتير والقيود مع بقاء أرقامها، سجل تدقيق كامل (من فعل ماذا ومتى مع القيم قبل/بعد)، قفل الفترات، والإقفال السنوي |
| الذمم | ربط سندات القبض والدفع بالفواتير (توزيع تلقائي الأقدم أولاً)، حالة السداد لكل فاتورة، وتقرير أعمار الديون |
| التقارير | ميزان المراجعة، كشف الحساب، قائمة الدخل، الميزانية العمومية، أعمار الديون، الإقرار الضريبي، وجرد المخزون حسب المستودع. كلها قابلة للطباعة |
| ✨ المساعد الذكي | يجيب عن أسئلتك بأرقامك الفعلية، ويحوّل وصف أي عملية بكلامك العادي إلى قيد محاسبي مقترح ترحّله أنت بضغطة زر |
| ✨ قراءة الفواتير | صوّر فاتورة المورد أو ارفع PDF، فتُعبّأ فاتورة الشراء تلقائياً وتُطابَق المواد مع الموجود لديك |
| ✨ التحليل المالي | تقرير ذكي في لوحة التحكم عن السيولة والربحية والديون، مع توصيات |

## الجاهزية التشغيلية

| البند | التفاصيل |
|---|---|
| البيع دون اتصال | إن انقطع الاتصال بالخادم تُحفظ فاتورة نقطة البيع على جهاز الكاشير وتُرحَّل تلقائياً. مرجع فريد لكل فاتورة يمنع تكرارها |
| ضبط الكاشير | صلاحية مستقلة للحسم وتعديل السعر، يتحقق منها الخادم (لا يُباع بأقل من السعر المعتمد بدونها). تعليق الفواتير واسترجاعها |
| فحص سلامة النظام | زر واحد يتحقق من توازن كل قيد، تطابق المخزون مع الحسابات، الكميات السالبة، الورديات المنسية، وحداثة النسخ الاحتياطي |
| النسخ والاستعادة | نسخة يومية + نسخة إلى مجلد إضافي (فلاشة/سحابة)، واستعادة بنقرة مع حفظ نسخة أمان قبلها ورفض الملفات التالفة |
| السجلّات | كل خطأ غير متوقع يُسجَّل في `data/logs` برقم مرجعي يظهر للمستخدم، ويُعرض من الإعدادات |
| الحماية | رفض طلبات التعديل القادمة من مواقع أخرى، كوكي آمن على HTTPS، قفل الدخول بعد محاولات فاشلة |
| الأداء | مُختبَر على ٥٠٠٠ مادة و١٢٠٠٠ فاتورة: حفظ الفاتورة ~٥٠ مللي ثانية، مسح الباركود ~١٦، التقارير أقل من ٦٠. القوائم الطويلة تُحمَّل على دفعات والبيانات تُضغط |

## البنية التقنية

```
backend/
  db.py          قاعدة SQLite والمخطط والترحيل التلقائي ودليل الحسابات الافتراضي
  accounting.py  محرك المحاسبة: الترحيل، الفواتير، الضريبة، العملات، المستودعات، الدفعات، الجرد، أوامر الشراء، التقارير
  auth.py        المستخدمون والصلاحيات وجلسات الدخول (قفل بعد ٥ محاولات فاشلة)
  tests/         اختبارات آلية (pytest) للمحاسبة والصلاحيات والإقفال
  devices.py     الطابعات (ESC/POS)، درج النقود، الميزان، ورسم الإيصال العربي
  ai.py          تكامل Claude: أدوات المساعد، قراءة الفواتير، التحليل
  app.py         واجهة REST (FastAPI) مع التحقق من الصلاحيات
static/          الواجهة الأمامية (HTML/CSS/JS، عربية من اليمين لليسار، مع وضع ليلي)
desktop.py       تشغيل البرنامج في نافذة سطح مكتب مستقلة
print_agent.py   وكيل الطباعة المحلي لجهاز الكاشير (يستقبل الإيصال من المتصفح ويطبعه)
data/            قاعدة البيانات accounting.db ومفتاح الذكاء الاصطناعي (.env)
```

- **كل رقم مصدره القيود:** الأرصدة والتقارير تُحسب دائماً من `journal_lines`، ولا يوجد رصيد مخزّن يمكن أن يختلف عن القيود. كل فاتورة وسند وتحويل يولّد أثره المحاسبي تلقائياً.
- **المساعد لا يكتب في دفاترك:** صلاحيته القراءة فقط (تشمل استعلامات SQL للقراءة، مع حجب بيانات الدخول)، ولا يُرحَّل أي قيد إلا بموافقتك وبصلاحية «قيود اليومية».
- **العملات:** النظام يسجّل الحركة بالعملة الأصلية ويحوّلها للعملة الأساسية بسعر الصرف وقت الحركة. لا يوجد حالياً إعادة تقييم آلية لفروق أسعار الصرف في نهاية المدة (تُدخل بقيد يدوي عند الحاجة).
- **النموذج:** `claude-opus-5` افتراضياً، ويمكن تغييره بمتغير البيئة `ACCOUNTING_AI_MODEL`.
- **النسخ الاحتياطي:** نسخة تلقائية يومية في `data/backups` (آخر ١٤ نسخة) مع فحص سلامة كل نسخة، وزر نسخة فورية في الإعدادات. في نسخة سطح المكتب المجمّعة تكون البيانات في `%LOCALAPPDATA%\SmartAccounting`.
- **الرقابة الداخلية:** لا شيء يُحذف أو يُعدَّل بصمت — كل عملية مسجَّلة في سجل التدقيق باسم المستخدم والوقت والقيم قبل/بعد، وأرقام المستندات من عدّادات لا تتكرر ولا تُعاد بعد الحذف.
- **التكلفة:** متوسط مرجّح لكل مستودع على حدة، والتحويل ينقل التكلفة مع البضاعة. الدفعات تتتبّع الكميات وتواريخ الصلاحية (التكلفة تبقى بالمتوسط المرجّح لا بتكلفة كل دفعة).
- **الطابعة ودرج النقود:** الإيصال يُطبع بمقاس 80 ملم عبر طابعة النظام؛ درج النقود الموصول بالطابعة يُفتح تلقائياً مع الطباعة حسب إعداد الطابعة. طباعة الملصقات تحتاج إنترنت لتحميل مكتبة الباركود مرة واحدة.
- **كلمات المرور** مخزّنة بتجزئة PBKDF2-SHA256 (200 ألف دورة) ولا يمكن استرجاعها — المدير يعيّن كلمة جديدة عند نسيانها.
